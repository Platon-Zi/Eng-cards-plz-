1. The idea behind the app

Two independent recall vectors, seven levels, a 30-day ceiling

The engine is classic spaced repetition: a word comes back exactly at the moment your memory of it starts to sag. What is different is the shape of the state — nothing is ever shuffled between containers. Every word carries its own clocks, and each clock is just a level plus a date.

🏦 The Bank stays silent

Imported words rest in the Bank (status: BANK). A Bank word is stored, not scheduled: it enters no queue until you consciously start learning it.

⚡ One answer activates it

Your first answer on a Bank word flips it to ACTIVE, sets both vectors to level 0 and makes them due today. This happens in Learn mode — or wherever else the word is served.

🧭 Two vectors, no gates

ENG ➔ RUS (recognition) and RUS ➔ ENG (production) live their own lives: separate level, separate due date. An answer touches only the side you just saw — the other is never moved, blocked or averaged. Reaching the second side is not a condition for advancing the first.

🔴🟢 Three answers, that is all

Forgot (🔴 «Забыл») resets that vector, Hard (🟠 «Сложно») freezes it at the current interval, Easy (🟢 «Легко») lifts it one level up. The old four-grade rating is gone — effort is expressed by the middle button.

The ladder: INTERVALS = [0, 1, 2, 4, 7, 14, 30]

A level is an index into that table; its value is how many days the next repeat waits. Six successful steps carry a vector from NEW to the ceiling.

📈 Groups are derived, never stored: a word reports as the group of its weaker vector — min(level_en_ru, level_ru_en); Bank words report as BANK. That is why the six dashboard rows can never drift out of sync with the data, and why there is no knowledge_group field to maintain.
🏆 Level 6 is a ceiling, not an exit: a MASTERED word returns after 30 days and stays in rotation for good. Nothing retires, nothing disappears — one slip lowers that single vector while the other side keeps its own schedule.
🎯 Reset is asymmetric: “Forgot” sends a vector to L1 up to level 3 and to L2 from level 4 up — the deeper the trace, the gentler the fall. “Hard” on L0 keeps the word eligible today by design (INTERVALS[0] = 0); the session de-duplicates it, and pressing Practice again later shows it once more.

2. Adding words & the AI prompt

Generate ready-made cards with Gemini / ChatGPT / Claude and import them

No manual typing of transcriptions, translations and examples: send your word list to any model together with this prompt. The prompt describes content only — scheduling is decided by the app, not by the model.

📋 Ready-to-use system prompt 
I will send you English words or lists of English words.
For every word build a JSON object with these mandatory fields:
- "word": the English word
- "phonetic": IPA transcription in square brackets, e.g. "[ˈɪnfluəns]"
- "translation": accurate Russian translation, marked by part of speech (сущ./гл./прил.)
- "part_of_speech": English part of speech ("noun", "verb", "adjective", "adverb", "phrase")
- "example": a natural, real-life English sentence using the word
- "example_translation": a fluent Russian translation of that sentence

Return ONLY a valid clean JSON array [ { ... } ] — no intro text, no markdown fences.

Step-by-step import:

  1. Copy the prompt above and send it to the model (Gemini, ChatGPT, Claude).
  2. Send the list of English words you want to learn.
  3. Copy the returned JSON.
  4. Open the ➕ Add Words screen in the app.
  5. Paste the JSON and press “🚀 Import Cards Now”.
  6. The words are tagged by part of speech, grouped into an import batch and placed in the Bank — nothing is scheduled yet.
  7. When you are ready, run 🏦 Learn New Words: the first answer on each word activates it and enrols both vectors into the schedule.
ℹ️ Field aliases are tolerated: transcription/phonetic and partOfSpeech/part_of_speech are read interchangeably, and a part of speech may arrive as an array — it is joined with / for display.

3. Data storage, transfer and backups

Offline-first files, the automatic safety snapshot and schema version 2

⚡ Offline-first

The app needs no server and no account. Everything runs from the project folder: open index.html and it works, airplane mode included.

📁 Where the data lives

Cards, history and batches are written to data/leitner_data.json, mirrored to data/leitner_data.js so the page can boot straight from a file, and cached in browser localStorage as the fast local copy.

🛟 Automatic snapshot

Before the very first save that converts an older library, the previous base is copied to data/leitner_data.pre-srs.json (plus the localStorage key leitner_data_pre_srs_backup) — once, and never overwritten.

💾 Manual backups

The Data & Backup section (left menu) offers “Save Backup (JSON)” and “Restore Backup”. A current dump carries schema_version: 2, so the app knows exactly which reader it is talking to.

♻️ Restoring an old backup

A pre-v2 file is migrated automatically on load: schedules are rebuilt from the legacy record, counters such as fail_count survive, and dead fields are dropped at the first save. Idempotent — a second pass changes nothing.

🚫 Forward compatibility warning

A schema_version: 2 backup cannot be read by an older build of the app. Keep the automatic snapshot, or upgrade every copy you use before restoring.

☁️ GitHub

Pushing the project to GitHub commits your whole progress, words and batches — nothing is lost on reinstall.

💻 Moving to another PC

Copy the folder or git clone it: batches and creation dates survive, because every card stores its own created_at. Dates are compared as local calendar days, so midnight and time zones do not shift your queue.

🛡️ Refuse-to-save guard: a write is rejected if it would leave fewer cards than the app already has, or if an ACTIVE word ends up with an unparsable review date. Your library is never silently shrunk.

4. Training modes

What each mode pulls and what it does to your schedule

🚀 Practice (Review)
The smart daily queue of due vectors.

It gathers every overdue direction of every ACTIVE word — a word with both sides due contributes two entries. Sorting puts the weakest levels first, then whoever has been overdue longest, then a seeded shuffle for variety; anti-adjacency spreads the two sides of one word apart. MASTERED support items ride at the end. No backlog cap: a long session simply ends where you stop it.

🏦 Learn New Words
First contact with the Bank.

Every Bank word produces two entries — ENG➔RUS and RUS➔ENG — rotated so the sides of one word are not neighbours, and both are served within the same session. The first answer (any of the three) activates the word and grades the shown vector; the later pass grades the independent second vector.

✍️ Spelling Studio
Dictation, typing and listening drills.

Letter-by-letter audio dictation, typing from audio or from translation, and a listening test with per-letter error analysis. It trains orthography and hearing — spelling answers do not move the two recall vectors.

📁 Groups & Packs
Targeted practice of a subset.

Drill words by import batch, by part of speech (only verbs, only nouns) or by your own custom groups. A group session uses the same vectors and the same intervals — it only narrows which words are offered.

🔀 Direction filter
Top-right of the training screen — it filters the output, it does not teach.
  • 🔀 Auto — serve the queue exactly as built, both vectors in one flow.
  • 🇬🇧 ENG→RUS — show only recognition entries of that queue.
  • 🇷🇺 RUS→ENG — show only production entries.

Progression is untouched either way: levels and dates advance as if the filter were not there.

🧠 Suggested rhythm: Learn a handful of Bank words once, then live in Practice every day. Accuracy counts “Hard” as correct-with-effort, so a green streak does not demand perfect speed.

1. Идея и смысл приложения

Два независимых вектора прогресса, семь уровней, потолок 30 дней

В основе — классические интервальные повторения: слово возвращается ровно тогда, когда память о нём начинает проседать. Изменилась форма состояния: ничего никуда не перекладывается. Каждое слово носит собственные часы, а каждые часы — это уровень плюс дата.

🏦 Банк молчит

Импортированные слова лежат в Банке (status: BANK). Слово в Банке хранится, но не планируется: оно не попадает ни в одну очередь, пока вы сознательно не начнёте его учить.

⚡ Активация одним ответом

Первый же ответ по банковскому слову переводит его в ACTIVE, ставит оба вектора на уровень 0 и открывает их к повтору уже сегодня. Это происходит в режиме 🏦 Learn New Words — и вообще везде, где слово было показано.

🧭 Два вектора без гейтов

ENG ➔ RUS (узнавание) и RUS ➔ ENG (воспроизведение) живут своей жизнью: отдельный уровень, отдельная дата. Ответ применяется только к показанной стороне — вторая не двигается, не блокируется и не усредняется. Никакой «второй верификации» для повышения не требуется.

🔴🟠 Три ответа, и это всё

Забыл отбрасывает вектор вниз, Сложно замораживает его на текущем интервале, Легко поднимает на уровень вверх. Прежняя четырёхкнопочная оценка ушла — усилие выражается средней кнопкой.

Лестница: INTERVALS = [0, 1, 2, 4, 7, 14, 30]

Уровень — это индекс в этой таблице, а значение — сколько дней ждёт следующее повторение. Шесть успешных шагов проводят вектор от NEW до потолка.

📈 Группы производные, они не хранятся: слово относится к группе своего слабого вектора — min(level_en_ru, level_ru_en); банковские слова показываются как BANK. Поэтому шесть рядов на дашборде физически не могут разойтись с данными, и поле группы не нужно поддерживать в актуальности.
🏆 Уровень 6 — это потолок, а не выход: MASTERED-слово возвращается через 30 дней и остаётся в ротации навсегда. Ничего не «увольняется» и не теряется: одна ошибка опускает только пострадавший вектор, второй идёт по своему расписанию.
🎯 Сброс асимметричен: «Забыл» уводит вектор на L1 вплоть до уровня 3 и на L2 начиная с уровня 4 — чем глубже след, тем мягче падение. «Сложно» на L0 оставляет слово доступным сегодня (INTERVALS[0] = 0); текущая сессия этот повтор уже не покажет, зато новое нажатие «Practice» в тот же день слово отдаст — так и задумано.

2. Занесение слов и промпт для нейросетей

Готовые карточки из Gemini / ChatGPT / Claude без ручного набора

Не нужно вручную вбивать транскрипции, переводы и примеры. Отправьте список слов любой модели вместе с этим промптом. Промпт описывает только содержание карточки — расписание решает приложение, а не модель.

📋 Готовый системный промпт для нейросети 
Я буду отправлять тебе английские слова или списки слов. 
Составь для каждого слова JSON-объект со следующими обязательными полями:
- "word": английское слово
- "phonetic": транскрипция в квадратных скобках (например, "[ˈɪnfluəns]")
- "translation": точный русский перевод с уточнением части речи (сущ./гл./прил.)
- "part_of_speech": часть речи на английском ("noun", "verb", "adjective", "adverb", "phrase")
- "example": жизненное предложение-пример на английском языке
- "example_translation": естественный перевод этого примера на русский язык

Возвращай ТОЛЬКО чистый валидный JSON-массив [ { ... } ] без лишнего вступительного текста и markdown-оберток.

Пошаговый процесс занесения:

  1. Скопируйте промпт выше и отправьте его боту (Gemini, ChatGPT, Claude).
  2. Отправьте список английских слов, которые хотите выучить.
  3. Скопируйте полученный от модели JSON.
  4. В приложении откройте экран ➕ Add Words.
  5. Вставьте JSON и нажмите «🚀 Import Cards Now».
  6. Слова получат части речи, соберутся в партию импорта и лягут в Банк — пока просто хранятся, ничего не запланировано.
  7. Когда будете готовы, запустите 🏦 Learn New Words: первый ответ по слову активирует его и введёт оба вектора в расписание.
ℹ️ Алиасы полей понятны движку: transcription/phonetic и partOfSpeech/part_of_speech читаются взаимозаменяемо, а часть речи может прийти массивом — для отображения он склеивается через / .

3. Хранение данных, перенос и резервные копии

Хранение без сервера, автоматический снимок перед миграцией и schema_version 2

⚡ Полностью офлайн

Серверы и аккаунты не нужны. Всё живёт в папке проекта: открыли index.html — и приложение работает даже без интернета.

📁 Где лежат данные

Карточки, история и партии пишутся в data/leitner_data.json, зеркалируются в data/leitner_data.js (чтобы страница стартовала прямо с диска) и кэшируются в браузере localStorage как быстрая локальная копия.

🛟 Автоматический снимок

Перед самым первым сохранением, которое преобразует старую базу, прежняя версия копируется в data/leitner_data.pre-srs.json (плюс ключ localStorage leitner_data_pre_srs_backup) — один раз и никогда поверх существующего.

💾 Ручные резервные копии

В разделе Data & Backup (левое меню) доступны «Save Backup (JSON)» и «Restore Backup». Свежий дамп несёт schema_version: 2, поэтому приложение сразу знает, какой формат ему принесли.

♻️ Восстановление старого бэкапа

Файл старше версии 2 мигрируется автоматически при загрузке: расписание пересобирается из старой записи, счётчики вроде fail_count сохраняются, мёртвые поля удаляются при первом сохранении. Процесс идемпотентен — второй проход ничего не меняет.

🚫 Предупреждение о совместимости

Бэкап с schema_version: 2 не читается старой версией приложения. Держите автоматический снимок или обновите все копии программы заранее, прежде чем восстанавливать такой файл.

☁️ GitHub

Пуш проекта в GitHub коммитит весь прогресс, слова и партии — при переустановке системы ничего не пропадёт.

💻 Перенос на другой компьютер

Скопируйте папку или сделайте git clone: партии и даты добавления выживают, ведь каждое слово хранит свой created_at. Даты сравниваются по локальному календарному дню, поэтому полночь и часовые пояса не сдвигают очередь.

🛡️ Защита от потери данных: сохранение отклоняется, если после записи карточек стало меньше, чем было, или если у ACTIVE-слова не разбирается дата повторения. Так слова не могут исчезнуть при сохранении.

4. Режимы обучения

Что каждый режим берёт и что делает с расписанием

🚀 Practice (Повторение)
Умная очередь долгов на сегодня.

Собирает все просроченные направления всех ACTIVE слов — слово с двумя просроченными сторонами даёт сразу две записи. Сначала самые слабые уровни, затем те, кто дольше в долге, дальше детерминированное перемешивание по ситу; анти-соседство не даёт двум сторонам одного слова идти подряд. MASTERED-поддержка едет в конец. Лимита нет: длинная сессия просто обрывается там, где вы остановитесь.

🏦 Learn New Words
Первое знакомство с Банком.

Каждое банковское слово даёт две записи — ENG➔RUS и RUS➔ENG, перемешанные так, чтобы стороны одного слова не шли соседями, и обе обслуживаются внутри одной сессии. Первый ответ (любой из трёх) активирует слово и оценивает показанную сторону; второй проход оценивает независимый второй вектор.

✍️ Spelling Studio
Диктант, печать и работа на слух.

Побуквенный аудио-диктант, набор слова со звука или с перевода и слушательный тест с разбором ошибок по буквам. Тренирует орфографию и фонематический слух — ответы в диктантах не двигают два вектора прогресса.

📁 Groups & Packs
Прицельная тренировка набора.

Учите слова партией импорта (слова конкретного дня), по части речи (только глаголы или только существительные) или по собственной созданной группе. Групповой прогон использует те же векторы и те же интервалы — он лишь сужает выдачу.

🔀 Direction filter
Переключатель в правом верхнем углу тренировки — только фильтр выдачи, на прогрессию не влияет.
  • 🔀 Auto — отдавать очередь как построена, оба вектора в одном потоке.
  • 🇬🇧 ENG→RUS — показывать из очереди только записи узнавания.
  • 🇷🇺 RUS→ENG — показывать только записи воспроизведения.

Уровни и даты продвигаются одинаково при любой позиции переключателя.

🧠 Рекомендуемый ритм: один раз пройти Learn по горстке слов, дальше жить в Practice каждый день. «Сложно» засчитывается как верный ответ с усилием, поэтому зелёная серия не требует идеальной скорости.

Клавиша Действие Описание
Space / S / Ы 🔄 Перевернуть карточку Переключает лицевую и обратную стороны карточки
