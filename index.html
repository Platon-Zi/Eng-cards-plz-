1. Идея и смысл приложения (Система Лейтнера)

Интервальное повторение для переноса слов в долговременную память

Приложение построено на методе интервальных повторений Себастьяна Лейтнера с двухсторонней верификацией (ENG ➔ RUS и RUS ➔ ENG). Слова не зубрятся вслепую, а повторяются ровно в тот момент, когда мозг начинает их забывать.

🏦 Bank (Box 0)
Банк новых слов
Сюда попадают все только что добавленные слова. Они ждут первого изучения в режиме Learn New Words.
Box 1 • Каждый день
Новые & Ошибки
Слова, которые вы только начали учить или в которых ошиблись. Требуют ежедневного повторения.
Box 2 • Раз в 3 дня
Первое закрепление
Слово вспомнилось без ошибок в Box 1 и перешло на следующий интервал.
Box 3 • Раз в 7 дней
Уверенное знание
Интервал увеличивается до недели. Мозг формирует прочные нейронные связи.
Box 4 • Раз в 14 дней
Долговременная память
Проверка через две недели. Слово почти перешло в активный запас.
Box 5 • Раз в 30 дней
Финальная проверка
Контрольный рубеж через месяц. Если слово вспомнилось — оно отправляется в Архив 🏆.
🔄 Двухсторонняя верификация: Чтобы слово перешло в следующую коробку, вы должны успешно вспомнить его в обоих направлениях (с английского на русский и с русского на английский). Любая ошибка сбрасывает слово в Box 1.

2. Занесение слов и Промпт для нейросетей

Как быстро генерировать и импортировать готовые карточки через Gemini / ChatGPT / Claude

Вам не нужно вручную вбивать транскрипции, переводы и примеры предложений. Отправьте список нужных слов любой нейросети с нашим готовым промптом:

📋 Готовый системный промпт для нейросети 
Я буду отправлять тебе английские слова или списки слов. 
Составь для каждого слова JSON-объект со следующими обязательными полями:
- "word": английское слово
- "phonetic": транскрипция в квадратных скобках (например, "[ˈɪnfluəns]")
- "translation": точный русский перевод с уточнением части речи (сущ./гл./прил.)
- "part_of_speech": часть речи на английском ("noun", "verb", "adjective", "adverb", "phrase")
- "example": жизненное предложение-пример на английском языке
- "example_translation": естественный перевод этого примера на русский язык

Возвращай ТОЛЬКО чистый валидный JSON-массив [ { ... } ] без лишнего вступительного текста и markdown-оберток.

Пошаговый процесс добавления:

  1. Скопируйте промпт выше и отправьте его боту (например, Gemini или ChatGPT).
  2. Отправьте боту список английских слов, которые хотите выучить.
  3. Скопируйте полученный от нейросети JSON.
  4. В приложении откройте вкладку ➕ Add Words.
  5. Вставьте JSON в поле и нажмите кнопку «⚡ Parse & Import Words».
  6. Слова автоматически распределятся по партиям импорта, получат части речи и попадут в Bank (Box 0)!

3. Хранение данных, перенос и резервные копии

Где лежат данные, как работает синхронизация с облаком и перенос на другой компьютер

📁 Где хранятся данные?

Все карточки, история, статистика и деление на партии хранятся прямо в файле data/leitner_data.json внутри папки проекта, а также дублируются в быстром локальном хранилище.

☁️ Облако и GitHub

Когда вы загружаете проект на GitHub, весь ваш прогресс, добавленные слова и группы фиксируются в репозитории. Данные никуда не исчезнут даже при переустановке системы.

💻 Перенос на другой компьютер

Если вы перенесёте папку с проектом на другой компьютер или сделаете git clone, деление на группы и даты добавления не пропадут! Каждое слово хранит свой уникальный timestamp и дату created_at.

💾 Ручные резервные копии (Safety Backup)

В левой панели всегда доступны кнопки «Save Backup (JSON)» (скачать файл базы на диск) и «Restore Backup» (мгновенно восстановить всю базу из сохранённого JSON-файла).

4. Режимы обучения и их предназначение

Как правильно тренироваться для максимального результата

🚀 Practice (Review)
Основной режим интервального повторения.

Собирает из Box 1–5 только те карточки, у которых наступил срок ревью на сегодня. Занимайтесь в этом режиме каждый день для идеального запоминания.

🏦 Learn New Words
Режим первого знакомства со словами из Банка (Box 0).

Карточки показываются в направлении ENG ➔ RUS. При нажатии «Помню» слово официально переходит в Box 1 и включается в интервальное расписание.

📁 Groups & Packs (Партии и Темы)
Целевая тренировка отдельных наборов.

Позволяет учить слова по партиям импорта (например, слова за конкретный день), по частям речи (только глаголы или существительные) или по кастомным созданным вами группам.

🔀 Direction Switcher (Направление)
Переключатель языка в правом верхнем углу тренировки:
  • 🔀 Auto — умный баланс 50/50, отдающий приоритет непройденной стороне.
  • 🇬🇧 ENG→RUS — тренировка восприятия английского языка (чтение и слух).
  • 🇷🇺 RUS→ENG — тренировка активного воспоминания и перевода на английский.

5. Горячие клавиши (Cheatsheet)

Управляйте тренировкой со скоростью мысли без мышки

Клавиша Действие Описание
Enter 🔊 Озвучить слово Произносит текущее английское слово с естественным акцентом
Shift + Enter (1-й раз) 💡 Показать подсказку Открывает предложение-пример с контекстом употребления
Shift + Enter (2-й раз) 🔊 Озвучить подсказку Произносит всё предложение-пример целиком
Space / S / Ы 🔄 Перевернуть карточку Переворачивает карточку между лицевой и обратной стороной
→ / D / В 🟢 Помню (Remembered) Ответ верен — продвигает карточку вперед по интервалу
← / A / Ф 🔴 Не помню (Forgot) Ошибка — сбрасывает карточку в Box 1 для повторения завтра
↓ (Стрелка Вниз) ↩ Отмена (Undo) Возвращает предыдущую карточку и восстанавливает её состояние
↑ (Стрелка Вверх) / W ⏭️ В конец очереди Откладывает текущую карточку на самый конец тренировочной сессии
0 – 5 📦 Переместить в Box N Вручную отправляет карточку в выбранную коробку от 0 до 5
Escape 🚪 Выход / Назад Закрывает открытые модальные окна или возвращает в Dashboard
